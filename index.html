Le fichier est stocké dans le navigateur de cet appareil. Pour les grosses vidéos, privilégie ton SSD sur PC.

Sauvegarde et restauration

Les fiches et fichiers sont conservés dans ce navigateur sur cet appareil. Ils ne se synchronisent pas automatiquement avec le PC. Fais des sauvegardes régulières ; effacer les données du navigateur peut effacer l'atlas. La sauvegarde contenant les vidéos peut être très volumineuse.
